# DIRM — prototype formulaires

Prototype Symfony des formulaires administratifs de la Direction interrégionale de la mer Méditerranée.

Le dépôt de travail suivi est [Dirm](https://github.com/Meriem1403/Dirm). Celui-ci sert de variante de développement.

## Stack

- PHP, Symfony
- MySQL
- Docker

## Démarrage

```bash
cp .env.example .env
docker compose up --build
```
